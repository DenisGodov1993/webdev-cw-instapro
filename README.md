# Instapro

MVP социальной сети для обмена фотографиями

## Первоначальная оценка
72 часа

## Фактически затраченное время
144 часов

# Какую фунциональность удалось реализовать:
- интегрировать верстку списка постов с API;
- страницу добавления поста;
- страницу с постами конкретного пользователя;
- функционал лайков.

# список дополнительных фич, которые удалось реализовать:
- функционал удаления собственных постов пользователя;
- верстка активного лайка;
- верстка кнопки удалить;
